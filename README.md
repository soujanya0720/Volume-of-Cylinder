# Volume of Cylinder

A simple C program that calculates the volume of a cylinder using the radius and height provided by the user.

## Formula

**Volume = π × radius² × height**

## Features

* Takes radius as input
* Takes height as input
* Calculates the volume of the cylinder
* Displays the result up to 2 decimal places

## Technologies Used

* C Programming

## How to Run

1. Clone this repository.
2. Open `volume_of_cylinder.c` in a C compiler or IDE.
3. Compile and run the program.
4. Enter the radius and height.
5. The calculated volume will be displayed.

## Example

text
Enter radius of cylinder: 5
Enter height of cylinder: 10
Volume of Cylinder = 785.40
